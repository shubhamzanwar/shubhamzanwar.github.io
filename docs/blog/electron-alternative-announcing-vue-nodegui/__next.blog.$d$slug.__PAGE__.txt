1f:T4829,<p>In this blog post, we shall take a look at vue-nodegui, a newly-released JS library to create cross-platform native desktop applications using VueJS 💚</p>
<ul>
<li>repo link: <a href="https://github.com/nodegui/vue-nodegui" rel="nofollow noopener noreferrer" target="_blank">https://github.com/nodegui/vue-nodegui</a></li>
<li>documentation site: <a href="https://vue.nodegui.org" rel="nofollow noopener noreferrer" target="_blank">https://vue.nodegui.org</a></li>
</ul>
<h3>Why not electron?</h3>
<p>Before we dive into vue-nodegui, let us discuss the most popular alternative out there: Electron ⚛️</p>
<p>Electron has been the most popular library for creating desktop applications using JS for a while now. While it is an amazing solution, it has some severe pain points by design:</p>
<ul>
<li>Electron apps tend to be bloated because every Electron app ships a version of the Chromium browser in which it runs. Hence, it's not <em>truly</em> native.</li>
<li>Electron apps also suffer from excess CPU/memory utilization issues.</li>
</ul>
<h3>What's vue-nodegui? 💚</h3>
<p>vue-nodegui is a custom vue3 renderer for <a href="https://github.com/nodegui/nodegui" rel="nofollow noopener noreferrer" target="_blank">nodegui</a>, a native JS bindings library for <a href="https://www.qt.io/" rel="nofollow noopener noreferrer" target="_blank">Qt5</a>. Below is an excerpt from the nodegui announcement last year:</p>
<blockquote>
<p>"<em>NodeGUI is powered by Qt5 💚 which makes it CPU and memory efficient as compared to other chromium based solutions like electron. NodeGui wants to incorporate everything that is good about Electron: The ease of development, freedom of styling, Native APIs, great documentation, etc. At the same time NodeGui aims to be memory and CPU efficient.</em>"</p>
</blockquote>
<p>vue-nodegui allows developers to use the familiar Vue API to create their native desktop app - something that react-native does for react. Since vue-nodegui is ultimately powered by Qt5, it means that vue-nodegui does not require a browser environment to render in. Instead, the widgets in the app are truly native.</p>
<h3>Features 💎</h3>
<ul>
<li>Access to new Vue3 features (<code>setup</code>, <code>composition api</code>, etc)</li>
<li>🧬 Cross platform. Should work on major Linux flavours, Windows and MacOS</li>
<li>📉 Low CPU and memory footprint. Current CPU stays at 0% on idle and memory usage is under 20mb for a hello world program.</li>
<li>💅 Styling with CSS (includes actual cascading). Also has full support for Flexbox layout (thanks to nodegui and Yoga).</li>
<li>✅ Support for all node_modules (compatible with Node v12 and above)</li>
<li>🎪 Native widget event listener support. supports all event available from Qt / NodeJs.</li>
<li>💸 Can be used for Commercial applications.</li>
<li>📚 Good documentation and website.</li>
<li>🧙‍♂️ Good documentation for contributors.</li>
<li>🦹🏻‍♀️ Good support for dark mode (Thanks to QT).</li>
</ul>
<h3>Requirements 📝</h3>
<p>Below are the general requirements for systems to create vue-nodegui apps:</p>
<ul>
<li>Only supported on 64bit OS.</li>
<li>CMake 3.1 and up (Installation instructions can be found here: <a href="https://cmake.org/install/" rel="nofollow noopener noreferrer" target="_blank">https://cmake.org/install/</a>)</li>
<li>Make, GCC v7</li>
<li>NodeJS v12.x and above</li>
</ul>
<p>You can find the detailed installation steps for each of the requirements and troubleshooting guide on the <a href="https://vue.nodegui.org/docs/guides/1-getting-started" rel="nofollow noopener noreferrer" target="_blank">Getting started</a> page.</p>
