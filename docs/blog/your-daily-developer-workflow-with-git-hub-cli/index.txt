19:T31b9,<p>If you're a software developer, there is a pretty high chance that you have used GitHub to host your code repositories. I'm sure you'll agree that it's an amazing place to host and showcase your projects💜. I'm also sure that you'll agree that vising the website to review pull requests, create an issue or release a, well, release is sometimes very frustrating - simply because it calls for so much context switching between your editor/terminal to your browser😖.</p>
<p>That's just not how things should work! 😤</p>
<p>Well, (thankfully) it seems like the unicorns at GitHub recognized this problem and have released the official GitHub CLI v1.0.0</p>
<p>In this blog post, I'll walk through my daily tasks as a developer and how I'm completely shifting my GitHub workflow to the cli🤩.</p>
<h3>What do I use GitHub for?</h3>
<p>Let's go over the tasks you and I would use GitHub for, while working on a project:</p>
<ol>
<li>Create issues</li>
<li>Assign issues</li>
<li>Create a PR that closes an issue</li>
<li>Review/merge a PR someone else has assigned to you</li>
<li>Create a release for your package</li>
</ol>
<p>Let's now bring all these tasks to our terminal so we don't have to log onto GitHub through the browser every time.</p>
<h3>Let's move to the CLI 🚀</h3>
<p>First things first, let's download the cli on our local machine. I'm using a macbook pro so I'll follow the instructions for it, but you can find the instructions for your OS <a href="https://github.com/cli/cli#installation" rel="nofollow noopener noreferrer" target="_blank">here</a></p>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="shell" data-theme="github-light github-dark"><code data-language="shell" data-theme="github-light github-dark" style="display: grid;"><span data-line=""><span style="--shiki-light:#6A737D;--shiki-dark:#6A737D"># Install with Homebrew</span></span>
<span data-line=""><span style="--shiki-light:#6F42C1;--shiki-dark:#B392F0">brew</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> install</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> gh</span></span></code></pre></figure>
<p>Once the download is complete, it's time to log into your account from the cli🔑. There are two ways of doing this. Either using a browser login, or by using a personal access token. I'll be showing the browser login, but the process it fairly simple for the personal access token too.</p>
<p>Run the following in your terminal:</p>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="shell" data-theme="github-light github-dark"><code data-language="shell" data-theme="github-light github-dark" style="display: grid;"><span data-line=""><span style="--shiki-light:#6F42C1;--shiki-dark:#B392F0">gh</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> auth</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> login</span></span></code></pre></figure>
<p>This will fire up an interactive program in your terminal that will ask you for your username and authenticate you using your browser</p>
<p>Follow the steps shown in the below recording</p>
<p><img src="/img/gh-cli-login.gif" alt="gh-cli-login"></p>
<p>You're all set to start using the gh-cli now 😁</p>
<p>Let's create our first repo on GitHub in which we'll perform all the other tasks. To do this, navigate to any git repo on your machine, in my case it is the <code>gh-cli-demo</code> repo, and run the below command</p>
<blockquote>
<p>Make sure you add atleast one commit on your master branch and push that to github</p>
</blockquote>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="shell" data-theme="github-light github-dark"><code data-language="shell" data-theme="github-light github-dark" style="display: grid;"><span data-line=""><span style="--shiki-light:#6F42C1;--shiki-dark:#B392F0">gh</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> repo</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> create</span></span></code></pre></figure>
<p>You will be greeted by a set of questions like below. Choose the appropriate responses and you'll be set. (<em>You can verify the repo creation by navigating to the link mentioned at the end of the interaction</em>)</p>
<p><img src="/img/gh-cli-repo-create.png" alt="gh-cli-repo-create"></p>
<p>We are ready to start working on our project now. Let's create an issue that we'll use to track our progress📝 (<em>In this case, our "dummy" issue will be addressed to adding a readme.md file for documentation</em>)</p>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="shell" data-theme="github-light github-dark"><code data-language="shell" data-theme="github-light github-dark" style="display: grid;"><span data-line=""><span style="--shiki-light:#6F42C1;--shiki-dark:#B392F0">gh</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> issue</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> create</span><span style="--shiki-light:#005CC5;--shiki-dark:#79B8FF"> --title</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> "Add documentation!!"</span><span style="--shiki-light:#005CC5;--shiki-dark:#79B8FF"> --body</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> "create a read me file describing what this repo is about"</span><span style="--shiki-light:#005CC5;--shiki-dark:#79B8FF"> --assignee</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> shubhamzanwar</span></span></code></pre></figure>
<p>In this case, we've used the <code>title</code>, <code>body</code> and the <code>assignee</code> flags. For the whole set, you can check out <a href="https://cli.github.com/manual/gh_issue_create" rel="nofollow noopener noreferrer" target="_blank">this page</a> from the cli documentation</p>
<p><img src="/img/gh-cli-issue-create.png" alt="gh-cli-issue-create"></p>
<p>Well, we've created the issue and it is assigned to us. Let's get cracking with it and create a readme file. We'll then raise a PR to merge our documentation into the master branch🚀. This part is probably already familiar to you. we use the good old <code>git</code> for this.</p>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="shell" data-theme="github-light github-dark"><code data-language="shell" data-theme="github-light github-dark" style="display: grid;"><span data-line=""><span style="--shiki-light:#6F42C1;--shiki-dark:#B392F0">git</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> checkout</span><span style="--shiki-light:#005CC5;--shiki-dark:#79B8FF"> -b</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> documentation</span></span>
<span data-line=""><span style="--shiki-light:#005CC5;--shiki-dark:#79B8FF">echo</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> "Demo repo to learn github cli"</span><span style="--shiki-light:#D73A49;--shiki-dark:#F97583"> ></span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> readme.md</span></span>
<span data-line=""><span style="--shiki-light:#6F42C1;--shiki-dark:#B392F0">git</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> add</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> readme.md</span></span>
<span data-line=""><span style="--shiki-light:#6F42C1;--shiki-dark:#B392F0">git</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> commit</span><span style="--shiki-light:#005CC5;--shiki-dark:#79B8FF"> -m</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> "adding documentation"</span></span>
<span data-line=""><span style="--shiki-light:#6F42C1;--shiki-dark:#B392F0">git</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> push</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> origin</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> documentation</span></span></code></pre></figure>
<p>At this point, our documentation changes are in the <code>documentation</code> branch. We ned to merge this with master. So let's create a PR that also references issue #1. Run the below command to create this PR from your terminal.</p>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="shell" data-theme="github-light github-dark"><code data-language="shell" data-theme="github-light github-dark" style="display: grid;"><span data-line=""><span style="--shiki-light:#6F42C1;--shiki-dark:#B392F0">gh</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> pr</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> create</span></span></code></pre></figure>
<p>This will prompt you for the PR title and the body and you can mention whatever is apt.</p>
<blockquote>
<p>If you want to use GitHub automation, you can type "closes #1" in the body of this PR. That way, github will automatically close the issue #1 when this PR gets merged😎</p>
</blockquote>
<p><img src="/img/gh-cli-create-pr.png" alt="gh-cli-create-pr"></p>
<p>Since we have created a PR, let's also play the role of out teammate and review/merge this PR. To do this, we can checkout to the PR locally, go through the code and then decide if we want to merge this or not.</p>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="shell" data-theme="github-light github-dark"><code data-language="shell" data-theme="github-light github-dark" style="display: grid;"><span data-line=""><span style="--shiki-light:#6F42C1;--shiki-dark:#B392F0">gh</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> pr</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> checkout</span><span style="--shiki-light:#005CC5;--shiki-dark:#79B8FF"> 2</span></span></code></pre></figure>
<p>Review the code now (well, in this case, it's your own code😂). Since everything is good, let's go ahead and merge this PR.</p>
<blockquote>
<p>In case you have comments/changes to request, you still have to use the browser. Hope github comes up with a cli solution for this too in later updates of <code>gh</code>🤞🏽</p>
</blockquote>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="shell" data-theme="github-light github-dark"><code data-language="shell" data-theme="github-light github-dark" style="display: grid;"><span data-line=""><span style="--shiki-light:#6F42C1;--shiki-dark:#B392F0">gh</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> pr</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> merge</span><span style="--shiki-light:#005CC5;--shiki-dark:#79B8FF"> 2</span></span></code></pre></figure>
<p>This again, opens up a prompt asking whether we want to squash/merge/rebase. Feel free to choose this according to your preference.</p>
<p><img src="/img/gh-cli-pr-merge.png" alt="gh-cli-pr-merge"></p>
<p>Yay! you've successfully merged your code into the master branch both locally and on remote without leaving your terminal. Cool, right? 🤘🏽</p>
<p>As a final step, let's create a new master release for our repo. (_This is usually used by libraries, but since we're trying everything out for our dummy repo, why not?_😉)</p>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="shell" data-theme="github-light github-dark"><code data-language="shell" data-theme="github-light github-dark" style="display: grid;"><span data-line=""><span style="--shiki-light:#6F42C1;--shiki-dark:#B392F0">gh</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> release</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> create</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> v1.0.0</span></span></code></pre></figure>
<p>This will ask you a few set of questions about the title, release notes, etc. You can fill this up according to your release spec. In this case, I've left the release notes blank.</p>
<p><img src="/img/gh-cli-release-create.png" alt="gh-cli-release-create"></p>
<p>There you go!🎉 You've successfully learned how to create a repo, create issues, raise and merge PRs, close issues and create releases - all from your terminal, thanks to GitHub cli.</p>
<p>This tool (obviously) contains a lot more features and more flags/options for each feature. You can check out the documentation <a href="https://cli.github.com/" rel="nofollow noopener noreferrer" target="_blank">here</a></p>
